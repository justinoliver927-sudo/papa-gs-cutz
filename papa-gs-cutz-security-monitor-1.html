Interpretation and limitations

Do not treat this page as a firewall or continuous security service. It runs browser-side checks when you press Refresh. It does not authenticate the owner, access private GitHub workflow logs, test database policies, scan the whole internet-facing attack surface, or automatically block attacks. Keep this page private if you later add sensitive operational details.

GitHub Pages serves static files. Never put a GitHub token, Supabase service-role key, password, recovery token, or other secret into this page. The Supabase project link is a dashboard shortcut only; it does not grant access by itself.
